# 2026 빅콘테스트 주제 1 — 기상 위기에 따른 취약 상권 영향 분석 (analysis 브랜치)

분석 코드·결과·문서를 모은 브랜치입니다. 코드 설명과 실행 순서, 주요 결과 수치는 `code/README.md`에 있습니다.

## 폴더
- `code/` 전처리 스크립트(01~09c), 분석 노트북(10~85), 공통 모듈, 손실 단가표·골목 상권·상권 지도 스크립트(90·95·96), `meta/` 업종 매핑표
- `outputs/tables/` 결과 표(csv), `outputs/figures/` 그림(png), `outputs/demo/` 데모 페이지(우천손실예보.html, 상권지도.html — 브라우저로 바로 열림)
- `data/external/` 기상청 관측·장기 ASOS·특보 이력 원본과 수집 기록. 서울 열린데이터광장·공공데이터포털·기상청 API허브에서 받은 큰 원본은 용량 때문에 넣지 않았고 `data/external/수집기록_*.md`에 출처·방법이 있습니다. 상가정보 원본은 `data-public` 브랜치에 있습니다.
- `data/processed/` 공공데이터에서 만든 중간 파일(날씨·특보·상가·서울 상권·생활인구·관광·온열질환). 신한카드·SK 유동인구에서 만든 중간 파일은 제공 데이터 규정 때문에 이 브랜치에 없습니다.
- `docs/` 분석 계획·정리, 제안서 초안, 파라미터 근거표, 골목 상권 후보, 레인체크 구현안, 회의 자료

## 실행
1. 제공 데이터(신한카드 `신한카드_데이터_레이아웃/`, SK `sk통신인구_데이터_레이아웃/`)를 저장소 루트에 둡니다.
2. `python code/run_all.py` 로 01~09 전처리를 돌립니다(09 계열은 외부 원본 폴더가 없으면 건너뜁니다).
3. `code/` 안에서 노트북을 10 → 20 → 30 → 40 → 50 → 60 → 70 → 80 → 85 순서로 실행합니다.

API 인증키(`.env`)는 저장소에 넣지 않습니다.
