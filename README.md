# 2026 빅콘테스트 주제 1 — 기상 위기에 따른 취약 상권 영향 분석 (강남구·춘천시)

분석에 사용한 코드와 가공 데이터만 모은 브랜치입니다. 결과 표·그림·데모 페이지와 보고서 원고는 `analysis` 브랜치에 있습니다.

## 구성

- `code/` 분석 코드. 실행 순서와 각 파일의 역할은 `code/README.md`에 있습니다.
  - `01~09c_*.py` 전처리(달력, 카드, SK 유동인구, 날씨, 패널, 장기 날씨, 특보, 상가정보, 서울·기상청·관광 외부 자료)
  - `10~85_*.ipynb` 분석 노트북(탐색, 민감도, 취약 지수, 예측·분류 모델, 장기·시나리오, 상가·지도, 튜닝, 알고리즘, 예보 백테스트)
  - `90_rate_table.py`, `95_alley.py`, `95b_alley_window.py`, `95c_alley_link_sensitivity.py`, `96_district_map.py`, `97_raincheck.py` 손실 단가표, 골목 상권 후보, 상권 지도, 레인체크 파라미터
  - `common.py`, `analysis.py`, `vulnerability.py`, `models.py`, `priority.py` 공용 모듈, `meta/` 업종 매핑표, `run_all.py` 전처리 일괄 실행
- `data/processed/` 공개 데이터에서 가공한 중간 파일(parquet): 날씨(일·시간·시간대·장기·평년), 특보, 상가정보, 서울 상권분석서비스 추정매출, 서울 생활인구, 관광데이터랩, 온열질환, 기상청 단기예보, 달력
- `data/external/수집기록_*.md` 외부 자료의 출처, 수집 방법, 실행 기록

## 넣지 않은 것

- 공모전 제공 데이터(신한카드, SK 유동인구)와 그로부터 만든 중간 파일(`card*.parquet`, `sk_*.parquet`, `model_panel_*.parquet`, `industry_profile.parquet`). 제공 데이터 규정 때문에 공개 저장소에 올리지 않습니다.
- 외부 공개 데이터의 원본 파일. 출처와 내려받는 방법은 `data/external/수집기록_*.md`에 있고, 용량이 작은 원본과 공공데이터포털 파일은 `data-public` 브랜치에 있습니다.
- 결과 표·그림·데모 페이지, 보고서 원고와 내부 문서는 `analysis` 브랜치에 있습니다.

## 다시 돌리는 방법

1. 제공 데이터를 저장소 루트의 `신한카드_데이터_레이아웃/`, `sk통신인구_데이터_레이아웃/`에 둡니다.
2. `python code/run_all.py`로 01~09 전처리를 실행합니다. 외부 원본이 없는 09 계열 단계는 건너뛰며, 그 결과는 이미 `data/processed/`에 있습니다.
3. `code/` 안에서 노트북을 10 → 20 → 30 → 40 → 50 → 60 → 70 → 80 → 85 순서로 실행한 뒤 90·95·95b·95c·96·97 스크립트를 실행합니다.

API 인증키는 루트의 `.env`에 두고 저장소에는 넣지 않습니다.
