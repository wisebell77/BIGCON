# data-public 브랜치: 분석에 쓴 공공데이터 원본

모두 무료·공개 자료입니다(출처·수집 방법은 analysis 브랜치의 `data/external/수집기록_*.md`). 용량 때문에 뺀 것과 제공 데이터는 아래에 적었습니다.

## 폴더
- `data/external/` 소상공인시장진흥공단 상가(상권)정보 2026.06. 강원 파일은 원본 그대로, 서울 파일은 원본(554,092행)에서 강남구 66,269행만 추린 것입니다(파일 이름은 원본과 같아 코드가 그대로 읽습니다). analysis 브랜치의 `data/external/`에 두면 됩니다.
- `Bigcon_data/` D 드라이브 원본 폴더 구조 그대로입니다. 환경변수 `BIGCON_EXT`를 이 폴더 경로로 두면 `code/09_seoul_external.py` 등이 읽습니다.
  - `공공데이터포털/` 춘천시 상권 매출현황(2023.7), 춘천사랑상품권 가맹점, 골목형상점가 현황(2024.12), 전통시장현황(2026.8), 전국전통시장표준데이터, 전국관광지정보표준데이터, 질병관리청 온열질환 감시 데이터
  - `서울열린데이터광장/상권분석서비스/` 영역-상권·영역-행정동 shapefile zip, 추정매출-상권·추정매출-행정동·점포-상권 연도별 zip(2021~2025), Open API로 받은 추정매출-자치구·길단위인구-상권·집객시설-상권·상권변화지표-상권 전체 CSV, API 명세(xls)

## 넣지 않은 것
- 서울 생활인구(행정동별, 월 zip 18개, 620MB)와 기상청 단기예보 격자 원본(gzip 5,900개, 150MB): 수집 기록의 주소에서 받거나 `code/09b_kma_forecast.py`로 다시 받을 수 있습니다. 정리된 결과(parquet)는 analysis 브랜치 `data/processed/`에 있습니다.
- 서울 상권 API의 페이지별 JSON 원본(api_raw/): 합친 CSV만 넣었습니다.
- 신한카드·SK 유동인구 제공 데이터와 그 파생 파일: 공모전 제공 데이터라 공개 저장소에 올리지 않았습니다.
