## 9. 정리와 할 일

근거가 분명한 것: 이벤트 정의(기상청), 틀(IPCC), 민감도·분포·확률(추정), 손실·순보험료·임계값 규칙(정의), 모델 파라미터·점수 방식(검증).

선택인 것 중 결과를 흔드는 것 순서
1. 증거 규칙(p<0.10, z<−1.96): 스윕에서 가장 큰 축. 사후 기대 β로 대체하면 임의 컷이 사라진다(백테스트 성적 비슷).
2. 시간대 β 문턱(5mm): 요율표의 20mm 이상 단가가 같아지는 원인. 연속 용량-반응(강수량의 함수)으로 바꾸면 구간별 차등이 생긴다.
3. 호우 문턱 10mm: 데이터 근거는 있으나 값은 선택. 5·15mm로 바꿔 결론이 유지되는지 표를 붙이면 된다.
4. 지수 가중치·등급 컷: 스윕으로 영향은 확인됨. 데이터 기반 가중치(실제 손실률과의 일치) 또는 예산 기준 컷을 대안으로 제시.
5. 분류 라벨 10%: 출처 확인 또는 정책 기준(지원 발동 손실률)으로 명시.
