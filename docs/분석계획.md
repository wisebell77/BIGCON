# 분석 계획 — 2026 빅콘테스트 주제 1 (기상 위기에 따른 취약 상권 영향 분석)

작성 2026-10-09. 팀 결정 사항을 반영한 확정본. 코드 실행법과 결과 수치는 `code/README.md`에 있다.

## 1. 문제 정의

설명자료의 최소 요구 성과물은 (1) 취약 상권·업종 도출과 피해 규모, 대응·지원 방안, (2) 기상·통신·카드 데이터 분석 근거와 방법론, (3) 상권별 기후 영향·피해 규모 예측·분류 모델과 성능평가, 재현 코드다. 이를 세 질문으로 바꾼다.

| 질문 | 산출물 | 노트북 |
|---|---|---|
| Q1. 폭염·열대야·호우가 있는 날 어떤 지역·업종·시간대·연령층의 매출이 평상시 대비 얼마나 변하는가 | 상권별 기상 민감도(감소율, 신뢰구간) | 20 |
| Q2. 무엇을 기후 취약 상권으로 정의하고, 어디가 취약하며, 피해 규모는 얼마인가 | 복합 취약 지수, 등급, 2025년 7~12월 손실액 | 30 |
| Q3. 예보가 주어졌을 때 상권별 피해를 미리 예측·분류할 수 있는가, 누구를 먼저 지원해야 하는가 | 예측·분류 모델(성능평가), 우선 지원 알고리즘, 대응 방안 | 40 |

용어
- 기상 이벤트: 폭염일(공식 일최고 33℃ 이상), 열대야(18시~익일 9시 최저 25℃ 이상), 호우(영업시간 06~24시 강수 10mm 이상, 20mm 구간 별도). 한파(일최저 −12℃)는 참고. 기상청 특보 기준(체감온도, 3시간·12시간 강수)도 같이 계산한다.
- 상권: 지역(강남·춘천) × 업종(×시간대). 카드 데이터가 시군구×업종 단위라 측정 가능한 최소 단위다.
- 취약: IPCC 틀. 위험 = 위해 × 노출 × 취약성(민감도, 적응능력). 민감도는 카드, 노출은 SK 유동인구와 이벤트 발생 시간대, 적응능력은 반등·소상공인 여부·외지인 비중.

## 2. 팀 결정(2026-10-09)

| 항목 | 결정 |
|---|---|
| 상권 단위 | 지역×업종(×시간대). SK는 시간대·연령·주말 구성으로 노출 보정에 사용. (2026-10-11 변경) 팀원이 올린 상가정보로 업종별 업소 수와 행정동 단위 취약 지도를 추가. 동별 민감도는 측정하지 않고 지역×업종 손실을 업소 수 비례로 배분 |
| 취약 판정 | 복합 지수(민감도·노출·적응능력 정규화 후 가중 결합), 상위 구간을 취약으로 |
| 이벤트 범위 | 폭염·열대야·호우 중심, 한파는 참고 |
| 소상공인 범위 (2026-10-11) | 민감도 추정은 대면 업종 전체. 취약 판정·등급·손실·우선순위·동 지도는 소상공인 중심 업종(small_biz=1)만. 골프장·놀이동산·대형마트·쇼핑몰 등 대형 업종은 '상권 앵커' 맥락으로만 언급 |
| 피해 규모 | 2025년 실제 이벤트일 손실 + 예보 기반 예측. 기후 시나리오(폭염일수 증가 등)는 장기 ASOS 자료를 받은 뒤 추가 |
| 강남 관측소 | 강남구 안 AWS(400) 우선, 빈 값은 서울 ASOS(108) |
