# 춘천 골목상권 정의 및 우천 위험 지수

## 1. 골목상권 정의

**근거**
- 「전통시장 및 상점가 육성을 위한 특별법 시행령」 제2조의2: 2,000㎡ 이내 점포 30개 이상, **단 지자체가 조례로 달리 정할 수 있음**
- 「춘천시 전통시장 및 상점가 육성을 위한 조례」 제24조 (2026.4.23 개정): **소상공인이 운영하는 점포가 2,000㎡ 이내에 15개 이상** 밀집한 구역
- 조례 제25조: 지정은 상인이 **구역 도면을 그려 신청** → 면적의 모양은 정해져 있지 않음

**우리 정의**
> 2,000㎡ 안에 소상공인 점포 15개 이상이 들어가도록 구역을 그릴 수 있는 골목.
> 구역 폭을 20m(골목 도로 약 6m + 양쪽 점포 깊이 약 7m)로 보아, **골목을 따라 100m 구간 안에 점포 15개 이상**이면 골목상권으로 판단.

※ 실제 '지정된' 골목형상점가가 아니라 **지정 기준을 충족하는 골목**임 (지정은 상인 1/2 이상 동의 필요)

## 2. 산출 과정 (`step1_zones.py`)

자료: 소상공인시장진흥공단 상가(상권)정보 (강원, 2026.6, 공공데이터포털) → 춘천시만 추출해 `data/`에 저장

| 단계 | 기준 | 이유 | 결과 |
|---|---|---|---|
| 0 | 춘천 전체 점포 | | 17,984 |
| ① | 생활업종 (음식·소매·수리개인·숙박·예술스포츠) | 골목 손님 장사 업종 | 13,759 |
| ② | 전통시장 반경 100m 제외 | 시장은 별도 제도 | 12,918 |
| ③ | 대기업 직영 추정 브랜드 제외 | 조례: "소상공인이 운영하는 점포" | 12,869 |
| ④ | 도로명이 '~길'인 점포만 | '~로·대로'는 대로변 | 6,735 |
| ⑤ | 같은 길에서 50m 이내로 이어진 점포를 한 구역으로 (15개 이상) | 끊기지 않은 골목 하나 = 한 구역 | 84구역 / 2,759 |
| ⑥ | 건물 3동 이상 | 아파트·복합 상가건물 1동 제외 | 77구역 / 2,514 |
| ⑦ | **골목 따라 100m 구간 안 15개 이상** | 조례 2,000㎡ 기준 | **58구역 / 2,171** |

- ⑤ 50m 묶기: DBSCAN(eps=50m, min_samples=3). 서로 50m 안 점포끼리 이어 붙임. 50m 넘게 끊기면 다른 구역 (같은 길 이름이 여러 구역에 나올 수 있음)
- ⑦ 100m 구간: 점포를 골목 방향으로 한 줄로 세우고 100m 자를 밀면서 안에 들어오는 최대 점포 수
- 구역 이름 = 구역 점포의 도로명주소 중 가장 많은 길 이름, 위치 = 점포 좌표 가운데값

**민감도**: 폭 25m(80m 구간) 50구역 / **폭 20m(100m) 58구역** / 폭 15m(133m, 도로 제외 산정) 69구역. 가장 엄격한 원형(반경 25.2m) 기준 충족 21구역은 모두 58구역에 포함. 위험 상위 10개는 기준을 바꿔도 거의 동일.

## 3. 우천 위험 지수 (`step2_risk.py`)

세 점수를 58개 구역 안 백분위(0~100)로 바꿔 평균

**① 예상 우천 손실 (만 원/일) — 추정값**
1. 신한카드 춘천 데이터로 업종별 "영업시간(06~24시) 비 10mm 이상인 날" 하루 매출 감소액 계산
2. 감소가 통계적으로 확실한 업종만 사용 (q<0.1), 나머지 0
3. 업종 감소액 ÷ 춘천 같은 업종 점포 수 = 점포당 평균 피해
4. 구역 안 점포의 점포당 피해를 합산

예) 1위 우석로79번길 (석사동, 47개)

| 업종 | 점포 | 점포당 피해 | 합계 |
|---|---|---|---|
| 한식 (춘천 하루 −1억 1,402만 ÷ 2,777곳) | 24 | 4.1만 | 98.5만 |
| 기타요식 | 13 | 4.5만 | 58.2만 |
| 일식 | 2 | 10.8만 | 21.5만 |
| 편의점 | 2 | 6.3만 | 12.6만 |
| 양식·제과점 | 2 | | 7.7만 |
| 노래방 등 4곳 | 4 | 0 | 0 |
| **합계** | 47 | | **약 199만 원/일** |

→ 실제 그 골목 매출을 잰 것이 아니라 **점포 구성으로 환산한 값** (같은 업종이면 매출이 같다고 가정). "피해가 실제로 컸던 골목"이 아니라 "피해가 몰릴 수 있는 골목"으로 해석.
구역별 업종 계산 내역은 `output/골목상권_위험지수.xlsx`의 '손실 계산 내역' 시트.

**② 비 취약 업종 비중 (%)**: 구역 점포 중 A(고민감)·B(중민감)군 비율. 업종군은 업종별 우천 효과를 묶은 것 (A: 커피·일식 등, B: 한식·의류·미용 등)

**③ 주말/평일 유동인구 비**: 구역 점포 반경 50m SKT 격자의 주말 ÷ 평일 유동인구. 1.1 초과면 '나들이·외지형'(레인체크 대상), 이하면 '주민 생활형'(사전 경보 대상)

## 4. 레인체크 연결
- 쿠폰 사용처 = 골목상권 58구역 소상공인 점포 (직영·대로변·상가건물 제외됨)
- 나들이·외지형 26구역 우선 → 비 예보 시 예상 손실 큰 골목에 쿠폰 배정
- 조례 제24조④: 골목형상점가 온누리상품권 가맹 권장 → 레인체크를 상품권·지역화폐로 지급, 상인회가 운영
