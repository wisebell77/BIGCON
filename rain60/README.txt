춘천 60년(1966~2025) 강수 추세 분석 (보고서 3.1)

자료: 기상청 기상자료개방포털 ASOS 종관기상관측 일자료, 춘천(101), 1966~2025 (raw/inner/*.csv, cp949)
실행 (이 폴더에서):
  python rain_60yr_trend.py   -> annual.pkl, trend.pkl (지표별 10년당 변화, 회귀 p, Mann-Kendall p, 전반/후반 30년 평균)
  python rain_60yr_plot.py    -> 60년 강수 추세 그림
주요 결과: 1시간 최다강수 36.0 -> 42.3mm(+17.5%, MK p=0.03), 1시간 30mm 이상 일수 1.1 -> 2.1일(+85%, MK p=0.02),
          연강수량·강수일수는 유의한 변화 없음
