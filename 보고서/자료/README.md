## 실행 방법

**레인체크 분석(`rc*.py`, `age.py`, `lego.py`)**

```bash
python 3.3_4.9_외지인구조_비뒤회복_rc.py <팀자료폴더> <신한카드_데이터2.txt 경로>
```

- `<팀자료폴더>/team/` 아래에 analysis 브랜치의 `code/meta/industry_map.csv`, `data/processed/calendar.parquet`, `weather_daily.parquet`, `tour_monthly_visitors.parquet`를 넣는다.
- 신한카드 데이터2는 공모전 제공 데이터라 저장소에 올리지 않았다.
- `rc2.py`, `rc3.py`는 같은 폴더의 `3.3_4.9_외지인구조_비뒤회복_rc.py`를 불러 쓰므로 같은 인자로 실행한다.

**관광지 거리(`6.3_*.py`)**

```bash
python 6.3_골목82_관광지거리_계산.py
```

관광지 위치는 관광지 바로 옆 가게(상가정보) 좌표로 잡은 대략값이다. 레고랜드는 상가정보에 없어 지도에서 읽은 대략값을 썼다.
